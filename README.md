# Zara Sales Analysis Dashboard

## Project Overview
An interactive sales analysis dashboard developed using Microsoft Excel to analyze product-level sales performance and explore trends across store positions, promotions, and seasonal categories.

## Tools & Techniques
- Microsoft Excel
- PivotTables and PivotCharts
- KPI cards
- Interactive slicers

## Key Metrics
- Product records analyzed: 252
- Total sales volume: 459,573
- Average sales volume: 1,823.70

## Project Files
- Zara_Sales_Analysis (1).xlsx — Excel workbook containing the dashboard and analysis.
- zara_sales_analysis.pptx — Project presentation.
